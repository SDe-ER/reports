This page lists every change in plain language, newest first.

:::note[Merged is not released, released is not deployed]
A change listed here is in the code once its pull request is merged. A site runs it only after that site is
upgraded.
:::

## Next release

### KSA VAT Return and KSA VAT Return Detail

- New report **KSA VAT Return**: the Saudi VAT return, fields 1 to 16, with amount, adjustment and VAT columns, and
  an A4 print view.
- New report **KSA VAT Return Detail**: the vouchers behind every amount, with invoice numbers, parties, tax IDs and
  totals, and Excel or PDF export.
- New form **KSA VAT Settings**: the Output VAT, Input VAT and VAT Settlement accounts of each company.
- Arabic translation of every label.
