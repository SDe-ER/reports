يعرض تقرير **تفاصيل إقرار ضريبة القيمة المضافة** (KSA VAT Return Detail) المستندات التي تكوّن كل مبلغ في
[الإقرار](/reports/ar/reports/ksa-vat-return/). يستخدم الحساب نفسه، فإجمالياته تطابق الإقرار دائماً.

## الفلاتر

| الفلتر | ملاحظات |
|---|---|
| الشركة، من تاريخ، إلى تاريخ | مطلوبة، وتُملأ تلقائياً عند فتح التقرير من مبلغ في الإقرار. |
| مبيعات / مشتريات | المبيعات أو المشتريات فقط. |
| تصنيف الضريبة | مبيعات أساسية، مبيعات محلية صفرية، صادرات، مشتريات أساسية، مشتريات صفرية. |
| النسبة (%) | مثلاً 15. |
| نوع الطرف، الطرف | عميل أو مورد واحد. |
| نوع المستند | فاتورة مبيعات، فاتورة مشتريات، قيد يومية، سند دفع. |
| إظهار القيود المستبعدة | يضيف القيود الافتتاحية والقيود بين حسابات الضريبة بلون باهت، مع السبب في الملاحظات. |

## الأعمدة

| العمود | المحتوى |
|---|---|
| تاريخ القيد | تاريخ المستند. |
| نوع المستند، رقم التسجيل على النظام | مستند ERPNext مع رابط لفتحه. |
| رقم فاتورة العميل / المورد، تاريخ الفاتورة | المشتريات: رقم فاتورة المورد وتاريخها. المبيعات: فاتورة المبيعات. القيود: رقم الفاتورة أو المرجع. |
| الطرف، اسم العميل / المورد | العميل أو المورد. |
| الرقم الضريبي | رقم التسجيل الضريبي للطرف. |
| تصنيف الضريبة، النسبة | مكان السطر في الإقرار. |
| التعديلات | مُعلَّم لإشعارات الدائن والمدين والمرتجعات. |
| المبلغ قبل الضريبة، الضريبة، الإجمالي شامل الضريبة | بعملة الشركة. |
| حساب الضريبة | حساب الضريبة الذي رُحِّل عليه المبلغ. |
| ملاحظات | سبب استبعاد السطر المستبعد. |

آخر صف هو إجمالي أعمدة المبالغ.

## التصدير

من قائمة التقرير: **تصدير** إلى Excel أو CSV، و**طباعة** أو **PDF** لملف PDF. التصدير يشمل الصفوف المفلترة والإجمالي.

## مراجعة إقرار

1. افتح الإقرار للربع.
2. اضغط على مبلغ الضريبة في البند 7 (المشتريات).
3. رتّب حسب **رقم فاتورة المورد** و**الرقم الضريبي**: السطور بلا رقم فاتورة أو رقم ضريبي تحتاج مراجعة قبل المطالبة
   بضريبة مدخلاتها.
4. فعّل **إظهار القيود المستبعدة** لترى قيود التسوية وإعادة التبويب في الفترة.
