# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Sijill, please report it **privately** by email to:

**info@sdce.sa**

Please do **not** open a public GitHub issue for security problems.

Include, where possible:

- a description of the vulnerability and its impact,
- steps to reproduce (with **invented data only**, never real company, customer, supplier or financial data),
- the affected version (`sijill` version from `bench version`) and the Frappe / ERPNext versions.

We will acknowledge your report, investigate, and coordinate a fix and disclosure timeline with you.

## Supported versions

Security fixes target the latest released version of Sijill on Frappe / ERPNext v16. Please upgrade to the latest
release before reporting.
